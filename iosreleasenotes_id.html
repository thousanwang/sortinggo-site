v1.9.9 2026-10

  • Baru: “Pustaka template format impor” dengan template siap pakai untuk Shopee, Shopline, Lazada, TikTok Shop, Shopify, Amazon, dan lainnya. Aplikasi mengenali laporan dan menyarankan template, pustaka diperbarui secara online, dan tombol “Periksa pembaruan” mengambil template terbaru saat itu juga.
  • Peningkatan besar format impor kustom: atur judul kolom, baris yang dilewati, urutan tanggal, isi dari baris sebelumnya, sheet pertama, jumlah 1 per baris, dan nama singkat produk multi-langkah; dilengkapi ringkasan, peringatan nama ganda, uji regex, dan prompt AI.
  • Kompatibilitas file lebih luas: masukkan kata sandi file Excel yang dilindungi saat impor; CSV／TXT mendukung UTF-8, Big5, GBK, Shift_JIS, EUC-KR; tanggal mendukung nama bulan bahasa Inggris (misalnya 03 Jun 2026).
  • Spesifikasi dan nama singkat produk lebih baik: Free／Lite kini menyimpan spesifikasi; variasi dari satu produk dapat memakai nama singkat yang sama, dan nama singkat tetap dipertahankan lewat kode produk setelah nama produk diubah.
  • Suara dan headset: mikrofon headset Bluetooth dapat dipakai untuk perintah suara, dan kontrol suara tetap berjalan setelah beralih ke aplikasi lain; perintah “selesai” dari headset berlanjut ke grup berikutnya yang belum selesai, dan aplikasi kembali mendengarkan setelah perintah cetak ulang.
  • Printer label Bluetooth: memperbaiki label yang kadang tidak tercetak saat mencetak berturut-turut.
  • Tampilan: skala font kini berlaku untuk tab, judul, dan menu; manajemen pesanan mendapat salin untuk menambah, ubah, dan hapus; memperbaiki deretan tombol bawah yang salah posisi setelah iPad diputar saat aplikasi di latar belakang.
  • Langganan dan bantuan: harga paket dan periode penagihan mengikuti wilayah App Store, dan pemulihan pembelian menampilkan hasilnya; kartu “Demo produk” di pusat bantuan dipindahkan ke paling atas dan menawarkan video skenario atau video cara penggunaan.

v1.9.5 2026-10

  • SortingGo untuk iOS kini hadir: berjalan di iPhone dan iPad (iOS 26 atau lebih baru) dengan fitur yang sama seperti SortingGo untuk Android v1.9.5.
  • Impor pesanan: Excel / CSV, format impor kustom, dan file Excel berkata sandi; pilih file dari perangkat, folder SMB / NAS di aplikasi File, atau SFTP.
  • Pekerjaan penyortiran: putting dan picking, alokasi dan persiapan, dengan panduan suara (termasuk lokasi penyimpanan), kontrol suara, dan tombol headset.
  • Cetak label: cetak label pengiriman melalui SortingGo Print Service atau printer label Bluetooth.
  • Templat urutan rute, pengelolaan nama singkat produk, ekspor file hasil Excel, dan koneksi gudang WarehousingGo.
  • Mendukung 9 bahasa, dilengkapi pusat bantuan dan tutorial interaktif; langganan dibeli dan dikelola melalui App Store.
