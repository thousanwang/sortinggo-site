Terima kasih telah membeli SortingGo Print Service!

Langkah 1 — Unduh SortingGo Print Service

Pilih versi yang sesuai dengan cara Anda ingin menjalankannya:

Disarankan: Installer Classic (berjalan sebagai Windows Service)

Otomatis berjalan saat Windows dinyalakan — tidak perlu login ke PC agar pencetakan label tetap berfungsi.

Unduh versi terbaru (GitHub Releases)

Alternatif: Microsoft Store (MSIX)

Berjalan sebagai aplikasi desktop biasa — Anda perlu login ke Windows agar aplikasi ini aktif.

Dapatkan di Microsoft Store

Langkah 2 — Instal di Windows

Jalankan installer yang sudah diunduh dan ikuti petunjuk di layar.

Langkah 3 — Aktifkan Lisensi Anda

Cara aktivasi tergantung pada bagaimana Anda melakukan pembelian:

  • Dibeli dari dalam aplikasi (dari halaman "Status Lisensi" pada SortingGo Print Service yang sudah terpasang): lisensi Anda sudah otomatis aktif saat pembelian — tidak perlu langkah tambahan.
  • Dibeli sebelum memasang aplikasi (misalnya melalui Lemon Squeezy, media sosial, atau iklan): periksa kotak masuk email yang Anda gunakan saat checkout untuk mendapatkan License Key Anda. Setelah memasang aplikasi, buka halaman "Status Lisensi" pada SortingGo Print Service dan masukkan License Key tersebut untuk mengaktifkannya.

Belum menerima email License Key? Mohon tunggu beberapa menit, lalu periksa folder spam sebelum menghubungi dukungan di bawah ini.
