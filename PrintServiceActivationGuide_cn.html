感谢您购买 SortingGo Print Service！

步骤 1 — 下载 SortingGo Print Service

请根据您计划的使用方式，选择合适的安装方式：

推荐：Classic 安装包（以 Windows 服务方式运行）

随 Windows 开机自动启动，无需登录电脑即可进行标签打印。

下载最新版本（GitHub Releases）

备选：Microsoft Store（MSIX）

以一般应用程序方式运行，需要登录电脑后才能使用。

前往 Microsoft Store 下载

步骤 2 — 在 Windows 上安装

运行下载的安装文件，并按照屏幕提示完成安装。

步骤 3 — 启用您的授权

启用方式取决于您的购买渠道：

  • 已在 App 内购买（在已安装的 SortingGo Print Service「授权状态」页面购买）：授权已在购买时自动完成启用，无需任何额外操作。
  • 安装前就已完成购买（例如通过 Lemon Squeezy、社群帖子或广告链接）：请查看您结账时填写的 Email 邮箱，获取您的 License Key（授权码）。安装完成后，打开 SortingGo Print Service 的「授权状态」页面，输入该授权码即可完成启用。

还没收到授权码邮件？请先稍等几分钟并检查垃圾邮件箱，若仍未收到请联系下方支持渠道。
