Thank you for purchasing SortingGo Print Service!

Step 1 — Download SortingGo Print Service

Choose the version that fits how you plan to run it:

Recommended: Classic Installer (runs as a Windows Service)

Starts automatically with Windows — no need to sign in to the PC for label printing to work.

Download the latest version (GitHub Releases)

Alternative: Microsoft Store (MSIX)

Runs as a regular desktop app — you'll need to be signed in to Windows for it to be running.

Get it from Microsoft Store

Step 2 — Install on Windows

Run the downloaded installer and follow the on-screen instructions.

Step 3 — Activate your License

How you activate depends on how you purchased:

  • Purchased inside the app (from the "License" page of an already-installed SortingGo Print Service): your license was already activated automatically at the time of purchase — nothing else to do.
  • Purchased before installing (e.g. via Lemon Squeezy, a social post, or an ad): check the inbox of the email address you used at checkout for your License Key. After installing, open SortingGo Print Service's License page and enter the License Key there to activate.

Haven't received your License Key email? Please allow a few minutes, then check your spam folder before contacting support below.
