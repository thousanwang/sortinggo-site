SortingGo Print Service를 구매해 주셔서 감사합니다!

1단계 — SortingGo Print Service 다운로드

사용 방식에 맞는 설치 방법을 선택하세요:

권장: Classic 설치 파일（Windows 서비스로 실행）

Windows 시작 시 자동으로 실행되어, PC에 로그인하지 않아도 라벨 인쇄가 가능합니다.

최신 버전 다운로드 (GitHub Releases)

대안: Microsoft Store（MSIX）

일반 데스크톱 앱으로 실행되며, 사용하려면 Windows에 로그인되어 있어야 합니다.

Microsoft Store에서 받기

2단계 — Windows에 설치

다운로드한 설치 파일을 실행하고 화면의 안내를 따라 설치를 완료하세요.

3단계 — 라이선스 활성화

활성화 방법은 구매 경로에 따라 다릅니다:

  • 앱 내에서 구매한 경우（이미 설치된 SortingGo Print Service의 "라이선스 상태" 페이지에서 구매）: 구매 시점에 자동으로 활성화가 완료되어 별도 조치가 필요하지 않습니다.
  • 설치 전에 먼저 결제를 완료한 경우（Lemon Squeezy, SNS 게시물, 광고 등을 통해）: 결제 시 입력한 이메일 주소의 받은편지함을 확인해 라이선스 키를 받으세요. 설치 후 SortingGo Print Service의 "라이선스 상태" 페이지를 열어 해당 라이선스 키를 입력하면 활성화가 완료됩니다.

라이선스 키 이메일을 받지 못하셨나요? 몇 분 정도 기다리신 후 스팸 메일함을 확인해 주세요. 그래도 받지 못하셨다면 아래 지원 센터로 문의해 주세요.
