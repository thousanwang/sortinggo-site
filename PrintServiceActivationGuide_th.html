ขอบคุณที่ซื้อ SortingGo Print Service!

ขั้นตอนที่ 1 — ดาวน์โหลด SortingGo Print Service

เลือกรูปแบบที่เหมาะกับการใช้งานของคุณ:

แนะนำ: ตัวติดตั้ง Classic (ทำงานเป็น Windows Service)

เริ่มทำงานอัตโนมัติพร้อมกับ Windows — ไม่ต้องล็อกอินเข้าเครื่องคอมพิวเตอร์ก็สามารถพิมพ์ฉลากได้

ดาวน์โหลดเวอร์ชันล่าสุด (GitHub Releases)

ทางเลือกอื่น: Microsoft Store (MSIX)

ทำงานเป็นแอปเดสก์ท็อปทั่วไป — ต้องล็อกอินเข้า Windows จึงจะใช้งานได้

ดาวน์โหลดจาก Microsoft Store

ขั้นตอนที่ 2 — ติดตั้งบน Windows

เรียกใช้ตัวติดตั้งที่ดาวน์โหลดมา แล้วทำตามคำแนะนำบนหน้าจอ

ขั้นตอนที่ 3 — เปิดใช้งานสิทธิ์การใช้งานของคุณ

วิธีเปิดใช้งานขึ้นอยู่กับช่องทางที่คุณซื้อ:

  • ซื้อภายในแอป (จากหน้า "สถานะสิทธิ์การใช้งาน" ของ SortingGo Print Service ที่ติดตั้งไว้แล้ว): สิทธิ์การใช้งานของคุณเปิดใช้งานอัตโนมัติตั้งแต่ตอนซื้อแล้ว ไม่ต้องทำอะไรเพิ่มเติม
  • ซื้อก่อนติดตั้ง (เช่น ผ่าน Lemon Squeezy โพสต์บนโซเชียล หรือโฆษณา): กรุณาตรวจสอบกล่องข้อความอีเมลที่คุณใช้ตอนชำระเงินเพื่อรับ License Key ของคุณ หลังจากติดตั้งเสร็จแล้ว ให้เปิดหน้า "สถานะสิทธิ์การใช้งาน" ของ SortingGo Print Service แล้วกรอก License Key นั้นเพื่อเปิดใช้งาน

ยังไม่ได้รับอีเมล License Key ใช่ไหม? กรุณารอสักครู่แล้วตรวจสอบโฟลเดอร์สแปมก่อนติดต่อฝ่ายสนับสนุนด้านล่าง
