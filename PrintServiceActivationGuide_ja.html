SortingGo Print Service をご購入いただきありがとうございます！

手順 1 — SortingGo Print Service をダウンロード

ご利用方法に合わせてどちらかをお選びください：

推奨：Classic インストーラー（Windows サービスとして動作）

Windows 起動時に自動で立ち上がるため、PC にサインインしていなくてもラベル印刷が可能です。

最新版をダウンロード（GitHub Releases）

代替手段：Microsoft Store（MSIX）

通常のデスクトップアプリとして動作するため、利用時は Windows へのサインインが必要です。

Microsoft Store から入手

手順 2 — Windows にインストール

ダウンロードしたインストーラーを実行し、画面の指示に従ってください。

手順 3 — ライセンスを有効化

有効化の方法は、ご購入いただいた経路によって異なります：

  • アプリ内で購入された場合（インストール済みの SortingGo Print Service の「ライセンス状況」ページから購入）：購入時点で自動的に有効化が完了しています。追加の操作は不要です。
  • インストール前に購入を完了された場合（Lemon Squeezy、SNS 投稿、広告経由など）：決済時に入力されたメールアドレスの受信箱をご確認いただき、ライセンスキーをお受け取りください。インストール後、SortingGo Print Service の「ライセンス状況」ページを開き、そのライセンスキーを入力すると有効化が完了します。

ライセンスキーのメールが届かない場合は、数分ほどお待ちいただいたうえで迷惑メールフォルダをご確認ください。それでも見つからない場合は、下記のサポート窓口までご連絡ください。
